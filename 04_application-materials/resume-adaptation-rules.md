# 简历适配通用规则

- 只使用 `01_profile/` 已确认的事实和真实 JD。
- 允许调整经历顺序、删减弱相关内容、优化动词和句式；职责归属、项目状态、时间、证书名称及量化结果须准确。
- 重要 JD 关键词只在有真实经历支撑时自然使用，不堆砌。
- 默认做一页 A4。空间不够时先删减弱相关内容，再压缩句子，最后才考虑微调版式。
- 由 `templates/` 中对应语言的 HTML 母版生成新文件，不覆盖母版。新文件保存到 `pending-review/公司-岗位/`。
- 生成前完整读取对应语言规则；中文设计岗可参考 `templates/resume-zh-reference.docx` 的视觉层级，但不得复制其中的虚构事实。
- 用浏览器检查 HTML 与打印预览：A4 尺寸、页边距、字号、间距和日期栏符合对应语言规则；无溢出、无遮挡、日期一致、链接正确，导出的 PDF 文字可选择复制。
- 每次交付附上改写说明和待用户确认清单。未经本人审核，不作为最终投递版。
